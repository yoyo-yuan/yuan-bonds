# 鸢报羁绊助手

帮助你收集、查询和记录《如鸢》与《代号鸢》的密探羁绊。

按密探查看羁绊搭配，根据当天的情报与天气查找可解锁组合，记录每一格的收集进度，让查漏补缺更方便。

## 主要功能

- **羁绊图鉴**：查看密探之间的「一拍即合」「貌合神离」羁绊，以及对应的情报与天气条件。
- **配对查询**：选择情报和天气，查找可解锁的密探组合，并直接标记完成。
- **进度记录**：查看每位密探和整体的收集进度，支持逐格勾选、整组全选和隐藏已完成密探。
- **筛选与搜索**：按名字、稀有度、部门、属性和完成状态查找密探。
- **双服与多账号**：分别记录如鸢、代号鸢的多个账号进度；当前服未开放的羁绊会标注提示，不计入完成数量。
- **密探管理**：标记尚未拥有的密探，切换查看「全部」或仅自己已拥有密探之间的羁绊进度。
- **备份与恢复**：导出 JSON 备份，导入时可选择合并进度或覆盖同名账号。

## 如何使用

1. 建立账号，选择游玩的版本：如鸢或代号鸢。
2. 在「管理拥有的密探」中标记尚未拥有的密探。
3. 在「开图鉴」中查看羁绊、勾选已解锁的格子；也可以在「查配对」中选择当天的情报与天气，寻找可解锁组合。
4. 定期在账号设置中导出备份，换设备或换浏览器时再导入。

进度保存在当前浏览器本地，不会自动跨设备同步。清除浏览器数据可能导致进度丢失，请妥善保存备份文件。

## 本地运行

需要 Node.js 24 或更高版本：

```sh
npm ci
npm run dev
```

然后打开 http://127.0.0.1:4173。请通过本地服务访问，不要直接双击打开 `index.html`。

项目使用 HTML、CSS 和原生 JavaScript，无需构建即可部署到 GitHub Pages 等静态网站托管服务。

## 开发与测试

主要文件：

- `index.html`：页面结构、使用说明与公告。
- `css/`：页面样式。
- `assets/weather/`：天气图标。
- `js/data/`：密探资料与羁绊数据。
- `js/core/`：账号、存档、羁绊计算与备份逻辑。
- `js/ui/`：各功能页面与交互。
- `tests/`：逻辑、页面交互和浏览器测试。

```sh
npm test                 # 逻辑与页面交互测试
npm run test:browser     # 桌面和手机尺寸的浏览器测试，需要安装 Google Chrome
npm run format:check     # 检查代码格式
```

测试覆盖双服进度计算、账号切换、旧存档迁移、备份导入导出及主要页面操作。修改羁绊数据或存档逻辑后，建议运行测试确认。
