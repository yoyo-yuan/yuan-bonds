# 鸢报羁绊助手

帮助你收集、查询和记录《如鸢》与《代号鸢》的密探羁绊。

今天的情报和天气能解锁哪些组合？还有哪些羁绊没收集？在这里查找搭配、手动标记进度，方便每天查漏补缺。

## 可以做什么

- **查询鸢报搭配**：选择情报与天气，查看可解锁的密探组合。
- **记录收集进度**：逐格勾选或整组全选，查看每位密探与整体的完成情况。未完成的密探优先显示，也可以隐藏已完成项。
- **筛选密探**：按名字、稀有度、部门、属性和完成状态查找羁绊。
- **收集战斗羁绊**：点击密探按钮筛选合击、援护、转移与急诊搭配，记录已收集／未收集状态。
- **管理多个账号**：为如鸢、代号鸢分别建立账号，独立保存各自的拥有情况与收集进度。
- **备份与恢复**：导出备份文件，换设备或浏览器后导入，继续记录。

## 开始使用

1. 点击顶部 **＋**，选择如鸢或代号鸢，为账号起个名字。
2. 在「管理拥有的密探」中标记尚未拥有的密探。
3. 打开 **「开图鉴」**，勾选已经收集的羁绊；每天也可以用 **「查配对」**，按当天的情报与天气寻找组合。
4. 点击顶部 💬 旁的 **⚔️**，进入战斗羁绊页面。选择密探、类型或收集状态，再点击格子记录进度。

战斗羁绊与鸢报图鉴共用密探拥有情况：未拥有的密探会在战斗页变灰，相关组合不可收集。获得密探后，在任一页面的「管理密探」中更新即可；已有的收集记录会保留。

战斗羁绊单独计算进度，不计入鸢报完成数量。再次点击 **⚔️** 或 **📋 更多**，即可从对应页面返回鸢报图鉴。

## 保存与备份

进度自动保存在**当前浏览器本地**，不会自动跨设备同步。清除浏览器数据可能导致记录丢失，建议定期备份。

在顶部 **⚙️ 账号设置**中导出或导入备份。备份包含所有账号的鸢报进度、战斗羁绊进度和密探拥有情况。

导入同名账号时可以选择：

- **合并**：保留双方已收集的进度；未拥有密探的标记也会合并。
- **覆盖**：用备份中的账号记录替换现有记录。若备份较旧，后来新增的进度也会被替换。

## 资料与反馈

如鸢与代号鸢的开放进度有所不同，鸢报图鉴中未在当前服开放的羁绊会单独标注，不计入完成数量。

战斗羁绊资料参考 [代号鸢 WIKI · 战斗羁绊](https://wiki.biligame.com/yuan/密探羁绊/太史慈甘宁#战斗羁绊)。战斗文本及最新资料可前往原页面查看，各服实装情况以游戏内为准。

发现资料有误，可以点击顶部 **💬 资料错误回报**反馈；遇到使用问题，也欢迎提交 Issue。
